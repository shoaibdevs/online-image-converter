## Setup

The first thing to do is to clone the repository:

```sh
$ git clone https://github.com/shoaibdevs/simply_convert
$ cd simply_convert
```

Create a docker container and run it:

```sh
$ docker-compose build
$ docker-compose up 
```

To stop dockor

```sh
$ docker-compose down
```


And navigate to `http://127.0.0.1:8000/
